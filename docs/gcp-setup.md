# 申请 Google OAuth 客户端凭据（照着点就行）

> 常见困惑：**「启用 API」之后页面不会给你任何密钥**。密钥在最后一步「创建 OAuth 客户端」后才生成，点「下载 JSON」就能拿到，然后在 GOOGLEd 里一键导入。

## 步骤

1. **启用 Drive API**（你已完成）
   打开 https://console.cloud.google.com/apis/library/drive.googleapis.com ，点「启用」。
   启用后跳转的「API/服务详情」页面**没有密钥**，这是正常的。

2. **创建凭据**
   就在上一步那个页面，点**右上角「创建凭据」**按钮 → 选「**OAuth 客户端 ID**」。

3. **配置同意屏幕**（第一次会强制弹出）
   - User Type 选 **外部** → 创建
   - 应用名称、邮箱随意填，一路保存
   - 在「**测试用户 / Test users**」里**添加你自己的 Gmail 地址**（测试模式下只有列出的用户能登录）

4. **创建 OAuth 客户端**
   - 回到「客户端 / Clients」页 →「**创建客户端**」
   - 应用类型选 **桌面应用**（Desktop app）← 一定要选这个
   - 点创建

5. **下载 JSON**
   创建成功的弹窗里点「**下载 JSON**」，保存到电脑。**客户端 ID 和密钥都在这个文件里**。
   （如果关掉了弹窗：在客户端列表里点你刚创建的客户端，右侧详情里也有 ID 和密钥，右侧还有下载按钮。）

6. **导入 GOOGLEd**
   打开 GOOGLEd → 首启向导（或「设置 → 账号」）→ 点「**📥 一键导入 Google 下载的 JSON**」→ 选中刚下载的文件 → 应用会自动弹出浏览器登录你的 Google 账号 → 授权后自动回到应用，完成。

## 为什么必须这一步？

任何桌面应用连 Google API 都需要一个「OAuth 客户端」来表明身份（就像 app 的身份证）。GOOGLEd 不内置公共凭据，是为了让你用自己的项目、自己的配额、数据只经过你自己的账号——这也是登录环节必须是「网页登录 OAuth」的原因：Google 只在官方页面验证你的密码，GOOGLEd 全程拿不到密码，只拿到访问令牌。

## 常见问题

- **403 access_denied「尚未完成验证流程」**：测试模式下，**谁登录就必须把谁加进测试用户**——即使用的是创建项目的同一个账号！两个解法：
  - **推荐（一劳永逸）**：控制台 → 「Google Auth Platform」→「受众(Audience)」→「发布应用」切成正式模式。个人使用不需要验证，登录时点「高级 → 继续前往」即可，且 token 不会 7 天过期。
  - 或者：「受众」页底部「测试用户」→「+ Add users」→ 添加你登录用的那个 Gmail。
  - ⚠️ 测试模式下 refresh token 只有 7 天有效期，7 天后要重新登录；发布成正式模式则无此限制。
- **登录开在了错误的浏览器/账号上**：GOOGLEd 已改为应用内独立登录窗口，与你的浏览器配置文件完全隔离，窗口里自己选账号即可。
- **浏览器打不开 Google 授权页**：先配好网络（GOOGLEd「设置 → 网络」切到自定义代理或 Workers 反代，token 交换会走同一通道）。
- **提示"应用未通过验证 / 未授权"**：正常，点「继续前往」即可；或检查测试用户有没有加你自己的 Gmail。
- **导入 JSON 提示没有 client_id**：创建客户端时应用类型没选「桌面应用」，重新创建一个选对类型即可。
